# infiniqeCRUDapp
 
Welcome to the infiniqeCRUDapp! This is a modern, responsive administrative interface built with the powerful Next.js 16 App Router.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS & Shadcn UI
- **Data Fetching & State:** TanStack Query (React Query) & Axios
- **Form Management:** React Hook Form
- **Validation:** Yup

## Key Features
- **URL-Based State Management for Search/Sort/Pagination to ensure shareable links and persistent state.**
- **Robust Data Fetching:** Uses TanStack Query for optimal caching, refetching, and state management.
- **Client-Side Validation:** Form inputs are safely validated using React Hook Form and Yup.
- **Modern UI/UX:** Styled using modern Tailwind CSS paradigms alongside accessible Shadcn UI components.

## Getting Started

First, install the necessary dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can use the top navigation or dashboard cards to jump between Products, Users, and Recipes.
